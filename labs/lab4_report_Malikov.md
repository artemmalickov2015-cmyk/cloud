# Лабораторная работа №4  
**Разработка инфраструктуры MVP AI-приложения**

## Цель работы  
Создать прототип AI-приложения с базовой функциональностью: спроектировать инфраструктуру, рассчитать экономическую модель и обосновать выбор облачных ресурсов для трёх стадий жизненного цикла.

---

## Описание приложения  

**Название:** FaceEthno AI (национальность по фото)

**Тип системы:** веб-приложение  

**Цель:** Определение предполагаемой национальности пользователя на основе загруженной фотографии лица с использованием алгоритмов компьютерного зрения.

**AI-компонент:** Кастомная нейросеть (Computer Vision), развернутая в контейнерах.

---

## Функциональные модули  

| Модуль | Frontend | Backend |
|--------|--------|--------|
| Загрузка фотографии | ✓ | ✓ |
| AI-анализ изображения | — | ✓ |
| Вывод результатов | ✓ | ✓ |
| Логирование ошибок | — | ✓ |

*(Примечание: Модули авторизации и админ-панели исключены для упрощения MVP)*.

# Стадия 1 — MVP  

## Цель  
Проверка гипотезы на реальных фотографиях при минимальных затратах.

## Стратегия  
Максимальная экономия. Один "легкий" контейнер обрабатывает и запросы, и AI-модель.

---

## Инфраструктура (GCP)

| Ресурс | Конфигурация | Обоснование |
|--------|-------------|------------|
| Cloud Run | 1 vCPU, 1 GB (App + AI) | Платим только во время обработки фото. Экономия на простоях. |
| Cloud Storage | ~10 GB | Хранение фото. Дешевле жестких дисков серверов. |
| Cloud SQL | db-f1-micro | Минимальная база для логов. |

# Стадия 3 — Production  

## Цель  
Обеспечить стабильную обработку фотографий от 100 000 пользователей в месяц без падений системы в пиковые часы.

## Стратегия  
Высокая доступность и масштабирование **внутри Cloud Run**. Добавление балансировщика для надежности.

---

## Инфраструктура (GCP)

| Ресурс | Конфигурация | Обоснование |
|--------|-------------|------------|
| Cloud Run (API) | Автоскейлинг | Обработка наплыва пользователей. |
| Cloud Storage | ~1 TB | Массивный архив фотографий. |
| Cloud SQL HA | Репликация (Master-Slave)| Защита от потери базы данных. |
| Load Balancer | Global | Распределение трафика и надежный IP. |

---

## Экономическая модель (Production)

| Ресурс | Стоимость |
|--------|----------|
| Cloud Run | ~$120 (зависит от пиков) |
| Cloud Storage | ~$26 |
| Cloud SQL HA | ~$100 |
| Load Balancer | ~$15 |
| **Итого** | **~$261/мес** |

# Обоснование выбора  

**Cloud Run** выбран как основа, так как Serverless-архитектура позволяет масштабироваться до нуля при отсутствии запросов, экономя бюджет, но при этом мгновенно реагировать на всплески трафика.

**Cloud Storage** является самым дешевым и надежным способом хранения тяжелых файлов (фотографий), исключая необходимость использовать дорогие жесткие диски серверов.

**Load Balancer** внедряется на этапе Production для обеспечения надежного IP, глобального распределения трафика и возможности подключения домена.
