# Лабораторная работа №4  
**Разработка инфраструктуры MVP AI-приложения**

## Цель работы  
Создать прототип AI-приложения с базовой функциональностью: спроектировать инфраструктуру, рассчитать экономическую модель и обосновать выбор облачных ресурсов для трёх стадий жизненного цикла.

---

## Описание приложения  

**Название:** AI сервис распознавания национальности по лицу (FaceEthno AI)

**Тип системы:** веб-приложение  

**Цель:** Определение предполагаемой национальности (или фенотипа) пользователя на основе загруженной фотографии лица с использованием алгоритмов компьютерного зрения.

**AI-компонент:** Кастомная нейросеть (Computer Vision), развернутая в контейнерах для анализа изображений.

# Стадия 1 — MVP  

## Цель  
Проверка гипотезы на реальных фотографиях с минимальными затратами.

## Стратегия  
Использование serverless-архитектуры (монолит) без оплаты за простой серверов.

---

## Инфраструктура (GCP)

| Ресурс | Конфигурация | Обоснование |
|--------|-------------|------------|
| Cloud Run | 1 контейнер (App + AI) | Платим только во время обработки фото |
| Cloud Storage | ~50 GB | Дешевое хранение загруженных фото |
| Cloud SQL | db-f1-micro (PostgreSQL) | Минимальная база для логов и юзеров |

# Стадия 3 — Production  

## Цель  
Обеспечить стабильную обработку "тяжелых" фотографий от 100 000 пользователей в месяц без падений системы в пиковые часы.

## Стратегия  
Внедрение асинхронных очередей, автомасштабирования и защиты от атак.

---

## Инфраструктура (GCP)

| Ресурс | Конфигурация | Обоснование |
|--------|-------------|------------|
| Cloud Run | Автоскейлинг (API + AI) | Обработка наплыва пользователей |
| Cloud Pub/Sub | Очереди сообщений | Защита AI-серверов от перегрузки фото |
| Cloud SQL HA | Репликация (Master-Slave)| Защита данных пользователей от потери |
| Cloud Storage | ~2 TB | Хранилище архива фотографий |
| Load Balancer | Global | Распределение трафика |
| Cloud Armor | WAF | Защита от DDoS и ботов |

---

# Обоснование выбора  

**Cloud Run** выбран как основа для всех этапов, так как бессерверная архитектура позволяет масштабироваться до нуля при отсутствии запросов, экономя бюджет, но при этом мгновенно реагировать на всплески трафика.

**Cloud Storage** является самым дешевым и надежным способом хранения тяжелых файлов (фотографий), исключая необходимость использовать дорогие жесткие диски серверов.

**Cloud Pub/Sub** внедряется на этапе Production, так как обработка изображений (Computer Vision) требует времени. Очередь не дает системе упасть, если тысячи людей загрузят фото одновременно.

**Cloud Armor и CDN** используются для защиты от вредоносного трафика и кэширования статики, что критично при аудитории в 100 000 пользователей.

# Вывод  

В ходе работы была разработана масштабируемая инфраструктура AI-сервиса по распознаванию национальности на основе фото.

Показано, что система плавно эволюционирует от дешевого MVP до высоконагруженного Production-решения. Специфика работы с изображениями потребовала внедрения объектного хранилища (Cloud Storage) на самых ранних этапах и очередей сообщений (Pub/Sub) на этапе Production для обеспечения бесперебойной работы нейросети. 

Использование бессерверных технологий GCP позволяет гибко управлять затратами, соотнося их с реальным количеством пользователей.
